# Athlete to Business（WEB教材・骨子デモ）

アスレチカ受講生向け 6回講座のWEB教材。スライドではなく、毎回このサイトでコンテンツを提供する。

## 構成
- `index.html` … 画面の枠（ナビ・表示モード切替）
- `assets/course.js` … **講座コンテンツのデータ**（全体像・6回分）。シナリオはここに投入する
- `assets/app.js` … データから画面を組み立てる処理（`#top` 全体像 / `#s1`〜`#s6` 各回）
- `assets/style.css` … デザイン

## シナリオの入れ方
`SESSIONS[n].steps` に、共通フォーマット①〜⑦ごとの内容を入れる。

```js
steps: {
  1: { prompt: '受講生への問い', facil: '目安10分／運営メモ' },
  // ...7まで
}
```
`draft: true` を付けると画面に「仮」ラベルが出る。

## 表示モード
- 受講生：問いとワークシートのみ
- 運営：運営メモ（目安時間・ファシリの注意点）も表示

ワークシートの入力内容は各自のブラウザ（localStorage）にのみ保存される。
